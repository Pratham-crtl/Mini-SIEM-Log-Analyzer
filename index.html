Mini SIEM Log Analyzer

🔐 A SOC-focused project for log monitoring & anomaly detection

📌 Overview

This project simulates a basic SIEM log analyzer. It parses authentication logs, detects anomalies such as brute force attempts, and generates visual reports.

🚀 Features

  • Parse Linux auth logs / Apache access logs
  • Detect brute force attempts
  • Generate CSV + chart reports

🛠️ Setup

git clone https://github.com/yourusername/Mini-SIEM-Log-Analyzer.git
cd Mini-SIEM-Log-Analyzer
pip install -r requirements.txt
python script.py
